# YouTube Video Generator — Orchestration Patterns

Reference guide for implementing the master orchestrator skill. Shows Agent tool
patterns, state threading, quality gates, error recovery.

---

## Agent Invocation Pattern

Each subagent is invoked via the Agent tool with:
- `subagent_type`: the agent type (e.g., `"claude"` for general-purpose)
- `description`: 3–5 word summary of what the agent does
- `prompt`: self-contained directive — no prior context, so brief the agent
  like they just walked in (explain what's happening, what you learned, what
  you need them to do)

Example:

```
Agent({
  subagent_type: "claude",
  description: "Research video topic and competitive landscape",
  prompt: `Research this topic for a YouTube episode.
  
  Topic: ${topic}
  Audience level: ${audienceLevel}
  ${draftContent ? `User's draft: ${draftContent}` : ''}
  
  Return a structured brief: [Core facts] [What existing videos cover] [Gap] [Sources].
  Never write script prose — this is research only.
  Be concise.`
})
```

**Result**: Agent returns a JSON/text report. Store it immediately — don't
re-derive it.

## State Threading (Agent Output → Next Agent Input)

Since each agent is fresh (no prior context), **extract and thread every
output explicitly**:

```javascript
// Step 6: Research
const researchBrief = await invokeAgent(/* ... */);
console.log("Research complete. Brief:", researchBrief.summary);

// Step 7: Script (local, uses research brief)
const scriptContent = await writeScript({
  researchBrief,
  audienceLevel,
  durationBudget
});

// Step 8a: Asset generation — pass script to asset agents
const visualTags = extractVisualsFromScript(scriptContent);
const realWorldTags = filterRealWorldArchitecture(visualTags);

if (realWorldTags.length > 0) {
  for (const tag of realWorldTags) {
    const archifyOutput = await invokeAgent({
      description: "Generate architecture diagram",
      prompt: `Generate a PNG diagram for this tag:
      ${tag.description}
      Episode folder: ${episodePath}
      Filename: ${tag.filename}`
    });
    // Store PNG path for asset-builder
  }
}

// Step 8b: Asset builder — pass script + archify results
const assetOutput = await invokeAgent({
  description: "Generate visual assets and thumbnails",
  prompt: `Generate visuals for this script.
  Script: ${scriptContent}
  Episode folder: ${episodePath}
  Already generated by archify: ${archifyFilenames}
  Format: ${format}`
});
```

**Key**: Each agent call includes only essential input (topic, prior output,
folder path). Never dump entire file contents unless necessary.

## Quality Gates Before Next Phase

After each agent completes, validate output before proceeding:

```javascript
// After Research
if (!researchBrief.core_facts || !researchBrief.gap) {
  console.error("Research output missing required fields");
  // Ask user: retry or proceed anyway?
  const retry = await askUser("Retry research?");
  if (retry) {
    return invokeAgent(/* same prompt */);
  }
}

// After Script write
const scriptFile = readFile(`${episodePath}/script.md`);
const visualCount = (scriptFile.match(/\[VISUAL:/g) || []).length;
const animationCount = (scriptFile.match(/\[ANIMATION:/g) || []).length;
const totalTags = visualCount + animationCount;

if (totalTags < minVisuals) {
  console.warn(`Visual density low: ${totalTags} tags (min ${minVisuals})`);
  // Ask user: approve anyway or expand?
}

// After Voiceover generation
const duration = getAudioDuration(`${episodePath}/voiceover.wav`);
if (duration < minDuration || duration > maxDuration) {
  console.error(`Duration ${duration}s out of range [${minDuration}, ${maxDuration}]`);
  console.log("Edit script.md, regenerate voiceover, try again");
  // Stop here — don't proceed to cue sheet
  return;
}

// After Video assembly
const videoFile = readFile(`${episodePath}/episode.mp4`);
if (!videoFile) {
  console.error("Assembler did not produce episode.mp4");
  // Ask: retry or proceed without video?
}

// Spot-check assembly output
const frames = extractFrames(`${episodePath}/episode.mp4`, [10, 30, 60]);
frames.forEach(frame => readFrame(frame)); // Visual inspection
```

## Error Recovery Strategies

### Retry with Context

If an agent fails, retry with:
1. Clearer prompt (add examples, step-by-step instructions)
2. Reduced scope (smaller task, fewer choices)
3. Different framing (different analogy, different angle)

```javascript
async function invokeWithRetry(params, maxRetries = 2) {
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      const result = await invokeAgent(params);
      if (validateResult(result)) return result;
    } catch (error) {
      console.log(`Attempt ${attempt} failed: ${error.message}`);
      if (attempt < maxRetries) {
        // Reframe the prompt slightly
        params.prompt += `\n\nPrevious attempt failed. ${error.message}. Try again with more detail.`;
      }
    }
  }
  throw new Error("All retry attempts exhausted");
}
```

### Skip Phase Gracefully

For non-critical phases (e.g., thumbnail generation), allow user to skip:

```javascript
const thumbnailResult = await invokeAgent({
  description: "Generate thumbnail candidates",
  prompt: `Generate 2 thumbnail PNG candidates...`
}).catch(async (error) => {
  const skip = await askUser(`Thumbnail generation failed. Skip?`);
  if (skip) {
    console.log("Skipping thumbnail generation");
    return null; // Mark as skipped, not failed
  }
  throw error;
});
```

### Fail Loud, Fail Clear

For critical phases, surface errors immediately:

```javascript
try {
  const videoFile = await invokeAgent({
    description: "Assemble final video",
    prompt: `...`
  });
  if (!videoFile || videoFile.status === "failed") {
    throw new Error("Video assembly failed: check cue sheet and assets");
  }
} catch (error) {
  console.error("❌ CRITICAL: Video assembly failed");
  console.error(`Error: ${error.message}`);
  console.error("Next steps: (1) Review cue-sheet.md for timing bugs");
  console.error("           (2) Verify all visuals exist in visuals/");
  console.error("           (3) Check voiceover.wav duration");
  console.error("           (4) Regenerate voiceover + cue sheet if script changed");
  throw error; // Stop orchestration
}
```

## Inter-Agent Communication (SendMessage)

If an agent is still running and you need to send it a follow-up:

```javascript
// Assume agent spawned and still processing
const agentId = "researcher-001"; // From Agent tool result

// Later: send follow-up question
await SendMessage({
  to: agentId,
  message: `One more thing: can you focus on the differentiation gap? 
  What does your research say existing videos miss about this topic?`
});

// Agent continues in same context; you get updated result
```

Use sparingly — usually a fresh agent with a complete prompt is clearer.

## Folder & File Management

At each step, verify folder structure:

```javascript
async function ensureEpisodeFolder(episodeNum, slug) {
  const path = `${projectRoot}/episodes/episode-${episodeNum}-${slug}`;
  mkdir(path);
  mkdir(`${path}/visuals`);
  mkdir(`${path}/thumbnails`);
  return path;
}

async function verifyAssets(episodePath) {
  const visuals = glob(`${episodePath}/visuals/visual-*.png`);
  const animations = glob(`${episodePath}/visuals/animation-*.mp4`);
  const voiceover = exists(`${episodePath}/voiceover.wav`);
  const cueSheet = exists(`${episodePath}/cue-sheet.json`);
  
  return { visuals, animations, voiceover, cueSheet };
}

async function cleanupDebugFiles(episodePath) {
  // Remove backup/superseded files
  const backups = glob(`${episodePath}/**/*-old-*.wav`);
  backups.forEach(f => rm(f));
}
```

## Logging & Continuity

Read series-log.md before starting (step 5):

```javascript
async function readSeriesLog() {
  try {
    const content = readFile(`${projectRoot}/series-log.md`);
    const rows = parseMarkdownTable(content);
    return rows;
  } catch (error) {
    console.error("❌ series-log.md missing or unreadable");
    console.error("Cannot determine next episode number");
    throw error;
  }
}

async function getNextEpisodeNum(rows) {
  const nums = rows.map(r => parseInt(r.Episode));
  return Math.max(...nums) + 1; // Zero-padded later
}

async function checkDuplicate(topic, rows) {
  const similar = rows.filter(r => 
    r.Topic.toLowerCase().includes(topic.toLowerCase()) ||
    topic.toLowerCase().includes(r.Topic.toLowerCase())
  );
  if (similar.length > 0) {
    console.warn(`⚠️ Potential duplicate:`);
    similar.forEach(r => console.warn(`  Episode ${r.Episode}: "${r.Title}"`));
    return true;
  }
  return false;
}

async function appendSeriesLog(episode) {
  const row = `| ${episode.num} | ${episode.slug} | ${episode.title} | ${episode.format} | ${episode.durationPref} | ${episode.slotRule} | yes | ${today} | ${episode.topic} |`;
  appendFile(`${projectRoot}/series-log.md`, `\n${row}`);
  console.log(`✅ Logged episode ${episode.num}`);
}
```

## Token Optimization Checklist

Before each agent invocation:

- [ ] RTK-wrap noisy shell output (e.g., `git log`, `find`, `ls -la`)
- [ ] Extract only essential facts from fetched URLs
- [ ] Never paste full file contents unless essential
- [ ] Summarize agent output in 1–2 lines before storing
- [ ] Use `rtk gain` at the end to report savings

Example:

```javascript
// ❌ Bad: full response stored
const research = await invokeAgent({...});
console.log("Research: " + JSON.stringify(research, null, 2));

// ✅ Good: extract, summarize, store
const research = await invokeAgent({...});
const summary = {
  facts: research.core_facts,
  gap: research.gap,
  sources: research.sources.map(s => s.url)
};
console.log(`Research: found ${summary.facts.length} core facts, gap: ${summary.gap}`);
storeForLaterSteps(summary);
```

## Example: Full Orchestration Flow (Pseudocode)

```javascript
async function orchestrateVideoProduction(userInput) {
  // Phase 1: Input Resolution
  const resolvedTopic = await resolveInput(userInput);
  console.log(`✓ Input resolved: ${resolvedTopic}`);

  // Phase 2: Orchestration
  // Step 5: Read continuity
  const seriesLog = await readSeriesLog();
  const episodeNum = await getNextEpisodeNum(seriesLog);
  if (await checkDuplicate(resolvedTopic, seriesLog)) {
    const proceed = await askUser("Proceed anyway?");
    if (!proceed) return;
  }
  const inputMode = detectMode(resolvedTopic); // SHORT or DRAFT
  const { duration, audienceLevel } = await askUserDurationAndLevel();
  const episodePath = await ensureEpisodeFolder(episodeNum, slugify(resolvedTopic));

  try {
    // Step 6: Research
    const researchBrief = await invokeAgent({
      description: "Research video topic and competitive landscape",
      prompt: `Research: ${resolvedTopic}, level: ${audienceLevel}, mode: ${inputMode}`
    });

    // Step 7: Script
    const scriptContent = await writeScript({
      topic: resolvedTopic,
      researchBrief,
      duration,
      audienceLevel,
      episodePath
    });
    if (scriptVisualCount(scriptContent) < minVisuals) {
      await askUser("Visual density low, expand?");
    }

    // Step 8: Assets
    const realWorldVisuals = identifyArchitectureTags(scriptContent);
    for (const visual of realWorldVisuals) {
      await invokeAgent({
        description: "Generate architecture diagram",
        prompt: `Generate: ${visual.description}, file: ${visual.filename}`
      });
    }
    await invokeAgent({
      description: "Generate visual assets and thumbnails",
      prompt: `Generate remaining visuals for script at ${episodePath}`
    });

    // Step 9: Voiceover
    const narrationTxt = extractNarration(scriptContent, episodePath);
    await generateVoiceover(episodePath, narrationTxt);
    const duration = checkAudioDuration(episodePath);
    if (duration < minDuration || duration > maxDuration) {
      throw new Error(`Duration ${duration}s out of range`);
    }

    // Step 10: Cue sheet
    const cueSheet = await invokeAgent({
      description: "Build cue sheet with word-level timestamps",
      prompt: `Build cue sheet for ${episodePath}`
    });
    await reviewCueSheet(episodePath);

    // Step 11: Video assembly
    const video = await invokeAgent({
      description: "Assemble final video with Ken Burns pans and animated clips",
      prompt: `Assemble video at ${episodePath}`
    });
    await spotCheckVideo(episodePath);

    // Step 12: Metadata
    await writeMetadata(episodePath, { scriptContent, duration, audienceLevel });

    // Step 13: Finalize folder
    await cleanupDebugFiles(episodePath);
    await displayFolderStructure(episodePath);

    // Step 14: Log + savings
    await appendSeriesLog({ num: episodeNum, slug: slugify(resolvedTopic), ... });
    await reportTokenSavings();

    console.log(`✅ Episode ${episodeNum} complete at ${episodePath}`);
  } catch (error) {
    console.error(`❌ Orchestration failed at step: ${error.step}`);
    console.error(`Error: ${error.message}`);
    console.error(`Folder preserved at: ${episodePath}`);
    throw error;
  }
}
```

## Debugging Tips

- **Agent hangs**: Check prompt — is it asking for something ambiguous? Add
  examples and concrete constraints.
- **Agent output format wrong**: Add validation after agent returns, call
  SendMessage to agent to fix format.
- **State lost between agents**: Explicitly store intermediate results to
  files (`script.md`, `metadata.md`, etc.) — don't rely on in-memory state
  across agent calls.
- **Timing issues in cue sheet**: Always read `cue-sheet.md` yourself before
  assembly. If it looks wrong, check `script.md` word-for-word alignment with
  `voiceover.wav` (use `ffplay`).
- **Video looks wrong after assembly**: Extract frames with `ffmpeg -ss <t>
  -frames:v 1` and visually inspect against `cue-sheet.md`. Don't trust
  agent's self-report.
