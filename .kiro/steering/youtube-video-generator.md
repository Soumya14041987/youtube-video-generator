# YouTube episode workflow

Use this when the user asks for a YouTube video, episode, script, thumbnail or upload details.

- The full workflow is the skill `youtube-video-generator`. Install it for Kiro once with `python3 scripts/install_ide.py --ide kiro`, then type `/youtube-video-generator`.

- Commands, layout and rules are in `AGENTS.md`. Setup for every IDE is in `docs/IDE-SETUP.md`.
