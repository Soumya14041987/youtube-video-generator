# Posting-window heuristic

This is a heuristic built from publicly reported LinkedIn engagement
patterns for B2B/technical audiences, not a live read of any account's
algorithm and not a prediction tool. Always label it as such in output —
never as a detected or personalized optimum.

## Default guidance

- **Best days:** Tuesday through Thursday. Monday competes with weekend
  catch-up; Friday afternoon and weekends see the steepest drop in
  professional-audience scroll time.
- **Best window:** 8:00-10:00am in the audience's primary timezone, with
  a secondary window at 12:00-1:00pm (lunch scroll). For a US-heavy
  technical audience, 8-10am ET covers the US East Coast open and catches
  US West Coast pre-work browsing.
- **Avoid:** late evening and Sunday — technical/B2B audiences skew
  toward workday scrolling far more than consumer platforms.
- **Cadence:** more than one post a day on the same account dilutes reach
  per post; back-to-back days on different topics is fine.

## How to use this in output

State the window, then one line of rationale, then the disclaimer:

```
Suggested window: Wed 8:30am ET
Why: mid-week, morning scroll, ahead of the AWS re:Invent news cycle you're riding on
Heuristic only — not a read of your account's actual reach data.
```

If the user's voice.md names a specific audience timezone or a different
posting history, prefer that over the US-ET default and say so.
